# MLAR Web Visualization

React/Vite viewer for MLAR architecture visualization payloads exported by the Rust crate.

The viewer is intended for quickly inspecting architecture hierarchy, graph connectivity, memory regions, processor functions, routers, resources, and scaled 2D mesh/core layouts.

## Requirements

- Node.js 18 or newer
- npm
- Rust/Cargo only when regenerating sample payloads from the main MLAR crate

## Run Locally

From the repository root:

```bash
cd web-visualization
npm install
npm run dev
```

Open the URL printed by Vite, usually:

```text
http://localhost:5173
```

The app loads `public/sample-viewer.json` by default through the runtime path `/sample-viewer.json`.

For a fixed host and port:

```bash
npm run dev -- --host 127.0.0.1 --port 5173
```

If the dev server is running on a remote machine, forward the port:

```bash
ssh -L 5173:127.0.0.1:5173 <user>@<remote-host>
```

Then open `http://127.0.0.1:5173` locally.

## Basic Usage

Use the header controls to load data:

- `Load URL`: fetches a JSON payload from the URL in the input. Files under `public/` are available from the server root, for example `/sample-viewer.json`.
- `Open File`: loads a local `.json` file from your machine.
- `Show JSON`: opens an editor for the currently loaded payload. Edits are parsed live.

When a hierarchy is present, the left panel shows the architecture tree. Nodes with an available graph are clickable. The main panel renders the selected graph with React Flow controls, minimap, zoom, pan, and draggable nodes.

The `Hardware` and `Processor` toggle changes graph presentation:

- `Hardware`: emphasizes hardware-level topology. For concrete 2D mesh payloads with intra-core data, it can render the core grid and inter-core memory links.
- `Processor`: renders processor/data-mover/resource relationships more explicitly.

Memory nodes and memory blocks inside core views can be clicked to open the memory detail panel.

## Supported Payloads

The runtime loader selects the parser by top-level `schema_version`:

- `mlar.arch-viewer.v1`: combined hierarchy plus graph map. This is the preferred payload for the full UI.
- `mlar.arch-hierarchy.v1`: hierarchy tree only. This shows the sidebar but has no graph unless paired in a viewer payload.
- `mlar.arch-graph.v1`: single graph only. This renders directly without a hierarchy sidebar.

The TypeScript runtime shape is defined in `src/schema.ts`. The standalone JSON schema currently covers the graph payload at `schema/architecture-graph.schema.json`.

## Regenerate Bundled Samples

The current sample viewer payload is generated by the 2D mesh Rust test:

```bash
cargo test test_export_2d_mesh_torus_viewer_json --test 2d_mesh
```

That writes:

```text
web-visualization/public/sample-viewer.json
```

You can also regenerate standalone graph and hierarchy payloads:

```bash
cargo test test_export_2d_mesh_torus_graph_json --test 2d_mesh
cargo test test_export_2d_mesh_torus_hierarchy_json --test 2d_mesh
```

Those tests write:

```text
tests/2d_mesh/2d_mesh_torus.json
tests/2d_mesh/2d_mesh_torus_hierarchy.json
```

Copy them into `public/` if you want to load them by URL from the web app:

```bash
cp tests/2d_mesh/2d_mesh_torus.json web-visualization/public/sample-graph.json
cp tests/2d_mesh/2d_mesh_torus_hierarchy.json web-visualization/public/sample-hierarchy.json
```

Then load `/sample-graph.json` or `/sample-hierarchy.json` with `Load URL`.

## Build

```bash
cd web-visualization
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Layout

- `src/App.tsx`: top-level viewer state, URL/file/editor loading, hierarchy selection, and view-mode controls
- `src/runtime-loader.ts`: fetch/file helpers and JSON parsing entry points
- `src/schema.ts`: TypeScript payload types and lightweight runtime validation
- `src/flow.ts`: conversion from MLAR graph payloads to React Flow nodes and edges
- `src/components/`: hierarchy, architecture node, core grid, core node, and memory detail components
- `public/`: JSON payloads served by Vite at `/...`
- `schema/`: JSON schema artifacts for exported visualization payloads
